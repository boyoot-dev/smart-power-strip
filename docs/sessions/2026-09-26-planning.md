## Key decisions and why
- **New repo** instead of extending the generic board: the strip has a fixed shape; the
  generic board is built around runtime pin assignment. Reuse TbLink + borrow web UI /
  time manager / automation code.
- **Fully isolated low-voltage side** (isolated PSU, Hall-effect current sensors,
  transformer voltage sensor, opto relay modules) → safe to have the ESP32 on USB during
  development, as long as no mains terminals are exposed.
- **One voltage sensor, two current sensors**: both outlets share the same L/N, so one
  ZMPT101B on the input side serves both; power per outlet = shared V × that outlet's I.
  Being on the input side also means voltage is known while outlets are off (useful for
  voltage-protection restore).
- **ADC dividers required**: sensors output up to ~4 V, ESP32 ADC takes ≤3.3 V (linear to
  ~2.5 V). Each of the 3 analog outputs goes through **10 kΩ top / 15 kΩ bottom** (×0.6)
  + **100 nF** to GND. Alternatives with ~0.6 ratio: 6.8k/10k, 4.7k/6.8k, 22k/33k.
  Optional 100 nF on each switch GPIO. No pull-up resistors needed (internal pull-ups).
- **Relay modules on High-level trigger** — 3.3 V GPIO can't reliably release a 5 V module
  in low-level mode.
- **Relay NO contact** → outlets go off if the ESP32 dies; "restore last" brings them back
  after boot.
- **Flip-toggle switches**: switch position is meaningless, any movement toggles — same
  idea as a staircase two-way circuit, with web UI / ThingsBoard as the "other" switch.
  Use the 2-terminal switches (3-terminal works with COM + one leg).
- **Protections are all per-outlet settings, default off** (compressor minimum off-time,
  voltage window, current limit, shed priority, after-trip behaviour) with one-click
  presets (Fridge/AC, Microwave/kettle, Generic). Overcurrent uses a 2 s RMS window so
  compressor/microwave inrush doesn't trip it.
- **Local history**: 7 days hourly + 90 days daily in LittleFS (one write/hour), last 24 h
  at 1-min resolution in RAM. ~15 KB RAM — negligible.
- **Display deferred to v2**; I2C pins 21/22 reserved.

## Safety points raised
- Mains only through wire + screw terminals, never breadboard/perfboard.
- Add a **16 A fuse/breaker** on the input (the one recommended exception to "no new
  hardware") — easiest: build inside an old power strip with a built-in breaker.
- Earth straight through to both sockets.
- Schuko plugs are reversible → an "off" outlet may still have live on one pin.
- Burn-in with the microwave at full power 10+ min; check ACS712/relay terminals for heat.
